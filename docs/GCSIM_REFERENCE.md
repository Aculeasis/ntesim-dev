# gcsim reference and NTE implementation mapping

Goal: accurate NTE team DPS across legal builds and authored rotations, with repeatable trials and explainable results under the [DPS relevance policy](../openspec/specs/product-scope/reference.md#dps-relevance-and-modeling-boundary). Architecture is a reference; NTE mechanics require independent evidence.

## Product decisions

- Follow the useful workflow: edit build and ordinary rotation, validate, run seeded sample, inspect action/damage/resource events, run many trials, compare and export reproducible inputs/results.
- Keep Rust as the sole product engine; do not adopt Go merely because upstream uses it. CLI and WASM share the same core.
- Preserve immutable evidence/quality contracts in addition to the reference's architecture. Unresolved damage dependencies are never silently defaulted; tested explicit hypotheses are allowed under the working rules, and strict remains an optional stronger policy.
- Use one public real combat-time axis and owner-defined Time Stop/process progress policies; internal clock research services remain independently bound. Upstream's Genshin frame rate, elements/reactions, artifact rules, animation cancels and game defaults are not NTE evidence.
- NTE console stats and item-specific substats are script-authored with `add stats` without modeling module geometry. Explicit research hypotheses remain a separate supported mode.
- Start with real supported scalar/build bindings and advance to complete ordinary actions and interaction adapters. More synthetic diagnostics alone do not make an analogue of the usable simulator.
- Shared-link hosting, account imports and server simulation are outside the approved local-first product; file import/export and local persistence satisfy the present scope.

The [OpenSpec changes](../openspec/README.md) tracks remaining work. Original ntesim code uses MIT. Architecture inspection is not authorization to copy upstream implementation or adopt its license; third-party attribution and distribution conditions remain separately reviewed.
