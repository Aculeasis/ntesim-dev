# Design

## Context

The CLI and Studio resolve equipment through the same Rust definition, progression and passive projection. Studio consumes the catalog generated by the native command and executes the Rust model in WASM.

## Decisions

- Bind the established S-rank level curve to the observed breakthrough and CRIT Rate progression. Store the published refinement coordinates in typed Rust and project them through the normal weapon adapter.
- Use the packet semantic declarations and existing AoE packet identity to track qualifying hits once per packet. Bind Haniel's published Hootie Follow-up Attack to its owner packets. Reuse the existing shared timed declarations for the two windows and for the paired wearer bonus.
- Apply the Redirect grant before same-time delivery and the DEF Ignore refresh in the post-hit callback phase. Read Cosmos penetration from live source modifiers at damage settlement.

## Risks and trade-offs

Combat-start order between equipped copies, post-Ultimate counter consumption and multi-target counting are explicit runtime assumptions pending a controlled client observation. Elyms's kit requires its own content change.
