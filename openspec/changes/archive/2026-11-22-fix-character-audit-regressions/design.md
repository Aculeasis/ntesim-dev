# Design

## Context

Public character builds feed both native script execution and Studio. Each actor contributes initial assumptions, while individual action descriptors contribute models for behavior they can reach. Raw simulation requests can still select specific evidence-bounded models for mechanics checks.

## Decisions

- Declare Adler's initial DEF and Aurelia's reaction passive in public build projection, where off-field actors can contribute without issuing a cast. Use shared breakthrough computation for their unlocks.
- Use Adler's existing two-volley model for public Burst so resource callbacks share the action timeline. Use the recovered Skill, Critical Dodge and Support producers for Cadenza and remove its Burst duration entry.
- Bind Lacrimosa's exit model and Baicang's entry prerequisites through the public action descriptors. The live script `window=swap` selector on Lacrimosa's dash yields at the existing recovery override. Keep the actual switch and its ETD-4, recovery and Cycle checks in runtime admission.
- Apply fallout at the source predicate. Chaos derives Warrant's tier bonus from actor configuration when its runtime cache is absent. Jiuyuan uses the same count-six resonance predicate where Pact status is applied. Mint compares exact HP fractions, including equality.
- Use frozen native progression text to correct Zero's documentation. The Cosmos Cycle trigger remains an unsupported dependency. Haniel requires explicit dummy ATK for reached extraction and Edgar's compiled build supplies its native base-HP provenance.
- Preserve the existing scope of the Scorch model. Adler's pending Temperance producer spans target resistance, ATK and incoming Break efficiency and requires its own lifecycle verification.

## Risks / Trade-offs

Public receipts can change where a newly selected model alters damage, resource timing or reaction follow-ups. Preserve per-model raw fixtures where they exercise an independent boundary and verify the public path separately.
