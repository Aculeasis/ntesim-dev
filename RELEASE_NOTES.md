# ntesim v0.1.0 — development snapshot

This version is an incomplete NTE team DPS simulator with a shared Rust CLI/WASM engine and React/TypeScript studio. Supported partial models execute damage, resources and selected equipment effects; no complete roster DPS baseline or public release is claimed. Reports retain incomplete quality and `game_dps_computed=false`.

Accepted requirements and active changes live in [OpenSpec](openspec/README.md). [Reproduction](docs/RUNBOOK.md) and [distribution requirements](openspec/specs/distribution/spec.md) own artifact usage and delivery. Current checks and declared model limits establish executable support. MIT applies to original code; third-party distribution needs artifact-specific review.
